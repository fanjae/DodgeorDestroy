# DodgeOrDestroy, 몰려오는 적을 피하거나 파괴하는 2D 슈팅 미니게임

<img width="620" height=420" alt="Image" src="https://github.com/user-attachments/assets/07ecb0ac-aceb-4b6f-8424-220dccf3925f" />

> Unity Input System과 Rigidbody2D 기반 이동, 적 스폰 및 다양한 이동 패턴을 활용해 만든 2D 슈팅 미니 게임입니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | DodgeOrDestroy |
| 개발 기간 | 2026.06.09 ~ 2026.06.09 |
| 개발 인원 | 1명 |
| 개발 환경 | Unity, C# |
| 실행 환경 | Windows |
| IDE | Unity Editor, Visual Studio 2022 |

## 실행 방법
1. Unity 프로젝트를 엽니다.
2. Unity Editor에서 Play 버튼을 눌러 실행합니다.

## 구현 기능

### ① 플레이어 시스템
- Input System 기반 이동 및 공격 구현
- 방향 전환 애니메이션 적용

### ② 적 시스템
- 코루틴 기반 적 생성
- 랜덤 스폰 및 다양한 이동 패턴 구현
- 적 HP 및 공격 기능 구현

### ③ 전투 시스템
- 플레이어/적 발사체 구현
- 충돌 기반 데미지 처리

### ④ 게임 진행 관리
- 점수 시스템 및 UI 갱신
- Life UI 및 게임 오버 처리
- 최종 점수 표시

## 조작 방법

| 키 | 기능 |
|:---:|---|
| 방향키 / WASD | 플레이어 이동 |
| Attack 입력 키 | 총알 발사 |
